# Findings

One file per source, named `<source-slug>-findings.md` —
`claude-findings.md`, `perplexity-findings.md`, and so on.

Copy [`TEMPLATE.md`](TEMPLATE.md) and fill it in. Keep the sections in
order and keep the verdict vocabulary closed (`adopt/reference` /
`differentiate` / `ignore`); put every "but" in Notes rather than in a
verdict cell, so the columns stay sortable and comparable across sources.

A question you found nothing for gets a `none found` row with the reason
in Notes. Silence is indistinguishable from not having looked.

**Without repo access:** paste the filled template back into the session
and it will be committed here unchanged.

**Do not read another source's findings before writing your own.** The
value of this pass is that the sources are independent; one framing
anchoring the next destroys it.
