# The detector corpus

**Type:** guide · [document types](../AGENTS.md#documents)

Examples with known answers, used to measure whether `praxis/signals.py`
agrees with what praxis claims a signal means.

## Format

One JSON object per line in `detectors.jsonl`:

```json
{"text": "Could you approve this by 3 p.m.?", "present": ["ask", "deadline"], "absent": ["uncertainty"], "source": "hand", "note": "a polite request is not a hedge"}
```

`present` and `absent` name only the detectors this example is *about*.
Anything unlisted is **unlabelled and not scored** — the same discipline
praxis applies to itself. An example that labels one detector is worth
more than one that guesses at twelve.

`source` records where the example came from, because it changes how much
the number is worth. Only `hand` and `review` (`measure.TRUSTED`) reach
the headline figure; the other two are reported beside it:

| `source` | Meaning |
|---|---|
| `hand` | Written by a person or from a real message. Ground truth. |
| `review` | A case a reviewer found praxis getting wrong. Ground truth, and the most valuable kind: it is a failure that actually happened. |
| `corpus` | Written while building the corpus, to pin a boundary the scores had just exposed. The label is usually obvious to anyone — "slipped by 5 days" is plainly not a deadline — but the *author* is the same one who wrote the pattern, so it is scored as its own tier rather than folded into the headline. |
| `generated` | Produced by a language model. **Weaker evidence** — see below. |

## Why `source` matters

The detectors were written by a language model. A corpus generated by one
tends to contain the cases its author already had in mind, which is
exactly the blind spot the corpus exists to expose. Generated examples
are accepted here, but they are scored separately and never counted
toward the headline figure alone.

A generated example is only worth having when the **label comes from the
prompt rather than the model's judgment** — "write twenty sentences that
mention updating and name no time" makes the category the label. Asking a
model to write a sentence *and decide* what is in it measures agreement
between two models, not correctness.
